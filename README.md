# Bento Grid

A responsive Bento Grid layout built using HTML5 and CSS3.

## Preview

Responsive dashboard-style layout inspired by the Frontend Mentor Bento Grid challenge.

## Features

- Responsive Design
- CSS Grid Layout
- Flexbox
- Media Queries
- CSS Grid Areas
- Google Fonts
- Reusable Card Components

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
